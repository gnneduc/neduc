# Checklist de validação

## Funcional

- [ ] Abrir a página inicial por HTTP.
- [ ] Navegar pelos sete itens do menu sem recarregamento completo.
- [ ] Atualizar e voltar pelo histórico do navegador.
- [ ] Acessar diretamente cada diretório de rota.
- [ ] Pesquisar e filtrar cursos, treinamentos, mentorias e artigos.
- [ ] Abrir todos os artigos AsciiDoc.
- [ ] Validar o formulário e confirmar abertura do cliente de e-mail.

## Responsividade

Testar pelo menos em 320, 375, 768, 1024, 1440 e 1920 px.

## Acessibilidade

- [ ] Percorrer todas as funções usando somente teclado.
- [ ] Confirmar foco visível e ordem de foco lógica.
- [ ] Testar zoom de 200% e 400%.
- [ ] Testar leitor de tela em títulos, menu, filtros, formulários e artigos.
- [ ] Confirmar que mensagens de status são anunciadas.
- [ ] Confirmar contraste com ferramenta automática.
- [ ] Testar `prefers-reduced-motion`.

## Conteúdo

- [ ] Revisar catálogo, datas, cargas horárias e disponibilidade.
- [ ] Confirmar domínio, e-mails e telefone.
- [ ] Revisar política de privacidade antes de integrar analytics ou formulários externos.
